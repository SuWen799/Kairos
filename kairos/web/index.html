🔌 MCP 外接工具

Model Context Protocol · 外部 server 的工具自动桥接进 Agent
📡 怎么接入微信 / 飞书 / QQ？
项目根目录 mcp.json（从 mcp.example.json 拷一份）里填 server 配置， "enabled": true，点「重连」——该 server 的所有工具自动以 mcp_服务名_工具名 加入 Agent 的工具集，对话里直接可用。
社区现成实现：飞书 larksuite/lark-openapi-mcp · 微信 wechaty 系 MCP · QQ NapCat/OneBot MCP · 文件系统/抓取 modelcontextprotocol 官方 servers

SQLite 8 表持久化 · SSE 流式 · 单文件零构建前端 · mcp.json 即插即用

· Dify（MIT）——知识库切片管道（400 字块+关键词检索，向量库在路线图）

· Manus ——工具执行过程实时可视化
· OpenHands / E2B ——受控代码执行（工作区沙盒 + 10s 超时的本地简化版）
· Meta Muse ——Forget 记忆删除、目标制后台任务、审批闸门设计
· 参考源码在 参考项目/，完整调研见 ../Agent全量调研与抄入清单.md
🧭 设计取舍（诚实声明）
没有整体搬 lobe-chat 的 React 工程：它自带一整套 LLM 网关/会话存储，与本项目 「FastAPI + SQLite + 工具白名单」的后端重复且冲突。做法是抄它的交互设计与视觉语言、 open-webui 的工作台信息架构，在自己后端上重实现——前端保持零构建依赖， 一份 index.html 可部署在任何静态服务器。
